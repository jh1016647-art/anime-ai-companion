# Love Letter: Aiko

A tiny browser-based romance game where an AI anime-inspired girl companion falls for you and responds to your messages.

## Features

- Anime-inspired character portrait
- Chat-based conversation system
- Affection meter and mood tracking
- Quick reply buttons for romance interactions
- Full browser gameplay with no install needed

## How to play

1. Open `index.html` in a browser.
2. Type messages into the chat box or use the quick reply buttons.
3. Build up Aiko’s affection to unlock more romantic dialogue.

## Files

- `index.html` — game structure
- `style.css` — anime-inspired styling and character art
- `script.js` — game logic, mood system, and chat responses

## Notes

This is a lightweight prototype designed to be easy to extend. You could later connect it to a real AI API such as OpenAI, Gemini, or a local LLM backend.
