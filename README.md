# Love Letter: Aiko

A small romantic anime companion game with a chat interface, affection system, voice input/output, and a soft bedtime scene.

## Run it as an app

This project is set up as a Progressive Web App (PWA), so you can install it like an app on supported browsers:

1. Open `index.html` in Chrome, Edge, or another modern browser.
2. Use the browser menu to install or add it to your home screen.
3. The game will behave like an app and work offline after the first load.

## Run it locally

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Features

- anime-style portrait and romance sim UI
- relationship meter and jealousy/intensity system
- text chat with quick-reply choices
- voice input and speech feedback
- bedtime and emotional scenes
- installable app experience via PWA

## Notes

This is a prototype focused on romance, character interaction, and dramatic dialogue.
